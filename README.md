# Naveen Kalapala - DevOps & SRE Engineer Portfolio

Welcome to the official portfolio of **Naveen Kalapala**, a passionate **DevOps & SRE Engineer** with experience at **Electronic Arts**. 

This portfolio showcases my technical skills, professional experience, and personal projects in a modern, responsive, and visually appealing website.

## 🚀 Features

- **🎨 Modern UI Design**: A clean and professional layout with a dark/light mode toggle for a customized browsing experience.
- **📱 Fully Responsive**: Optimized for all device sizes, from mobile phones to large desktops.
- **✨ Smooth Animations**: Scroll animations, hover effects, and seamless transitions to keep the user experience dynamic and interactive.
- **📝 Functional Contact Form**: Integrated with Formspree to easily send messages directly from the website.
- **🖼️ Profile Section**: Featuring a personalized profile with your image and professional details.
- **🚀 Performance Optimized**: Fast loading time and smooth interactions to enhance user experience.

## 🔧 Technologies Used

- **HTML5** - Structuring content with modern web standards.
- **CSS3** - Styling with responsive layouts and animations.
- **JavaScript** - Dynamic interactions and smooth user experience.
- **Font Awesome Icons** - Beautiful and scalable icons for a modern touch.
- **Google Fonts** - Poppins & Montserrat for a sleek, modern typography style.
- **Formspree** - For handling and sending contact form submissions.
- **GitHub Pages** - Free hosting solution for deploying the portfolio website.

## 🛠️ How to Use

### I. Clone the repository:

```bash
git clone git@github.com:nkalapala12/naveenkalapala.github.io.git
cd naveenkalapala.github.io
```

### II. Add your profile photo:

- Place your photo named `Naveen Kalapala.jpg` in the root directory of the project.

### III. Customize content:

1. Open `index.html` in your favorite code editor (VS Code, Sublime Text, etc.).
2. Update the text content to reflect your own personal information (name, title, bio, etc.).
3. Modify the social media links (LinkedIn, GitHub, etc.) to point to your own profiles.

### IV. Host on GitHub Pages:

1. Create a new repository on GitHub (ensure the repository is public).
2. Push the code to the `main` branch of your new GitHub repository.
3. Go to the repository **Settings > Pages** section.
4. Under **Source**, select **Deploy from branch**, and choose the `main` branch.
5. Your portfolio will be live at: `https://<username>.github.io/<repository>`.

### V. Contact Form Setup:

The contact form is pre-configured to work with my **Formspree** endpoint. To set up your own:

1. Go to [Formspree.io](https://formspree.io) and sign up for an account.
2. Create a new form and obtain your unique Formspree endpoint URL.
3. Replace the existing Formspree endpoint in `index.html` with your own:

```html
<form id="contact-form" action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

### VI. Customization

- **Profile Photo**: Replace `me.jpg` with your own profile image.
- **Social Links**: Update the social media URLs in both the About section and Footer with your own.
- **Skills**: Modify the skill categories and progress levels in the Skills section according to your expertise.
- **Experience**: Update the experience cards with your own job details and projects.
- **Color Scheme**: Customize the color scheme by adjusting the CSS variables in `:root` for global colors, and `.dark-mode` for the dark theme.
